# 穴場 一都三県

## 概要

1都3県の穴場スポットを中心とした観光・飲食・宿泊情報を、地図上で検索・閲覧できるWebアプリケーションです。

地域・カテゴリ別フィルター／検索機能を実装し、目的に合ったスポットを効率的に探せるようにしました。

## 主な機能

* Google Maps API連携によるスポット表示
* 地域・カテゴリ別フィルター／検索
* スポットの詳細情報表示
* スポット推薦掲示板
* 会員登録／ログイン機能
* マイページ
* スポット登録申請・管理者による承認・登録
* Oracle Databaseとの連携

## 使用技術

* Java
* JSP & Servlet
* JavaScript
* CSS
* Oracle
* Eclipse
* MVC
* Google Maps API
